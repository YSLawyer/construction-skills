# 《合同静态审查四步法》

## R — 原文 (Reading)

> 合同静态审查，指的是对合同基本要素进行审查……由合同关系、合同内容、合同性质、合同效力依次递进。在确定合同效力之后，涉及的就是释明权的行使问题。（第三篇 合同静态审查 开篇）

---

## I — 方法论骨架 (Interpretation)

法官审合同本身，按「关系→内容→性质→效力」四步递进；律师把它镜像成四道开庭前的自检动作，每一道都在法官开口前先做掉：

1. **关系**：法官先查「谁和谁有合同关系、能否突破相对性」。律师则在起诉前先锁定**真正的付款义务人**——核有无书面合同/中标通知书、签字人是有权代表还是表见代理、是否挂靠/指定分包，据此决定起诉谁、追加谁、主张谁连带，避免像案例9-6那样告错人全盘败诉。
2. **内容**：法官按「合同形式→10项内容要点→招投标文件→矛盾/约定不明」查双方权利义务。律师则**补强己方有利约定**（价款、承包范围、计价方式、付款节点、结算方式、工期、质保金），并提前调取招投标文件、补充协议、签证单、结算文件，锁定结算依据，堵住对方「约定不明」的抗辩。
3. **性质**：法官问「标的是否建设工程、是否建设工程合同、属哪一种」。律师则把合同**往对己方有利方向定性**——要专属管辖/主张无资质无效就咬定「名为XX实为建设工程施工合同」，要避开工期质量连带/主张仅买卖合同则反向论证；同时预判对方定性并备好反驳证据。
4. **效力**：法官对效力「主动审查、必须审查、不得有误」。律师则做**效力攻防**——对己方不利的有效合同主动主张无效（无资质、挂靠、应招未招、中标无效、无规划证、违法分包/转包/支解发包、通谋虚伪），对己方有利的合同则补强有效证据（资质证书、招标手续、规划证、分包经发包人同意）。

每一步律师都同时准备「我方主张 + 对方最可能的主张 + 反证」，并预判法官释明点，主动引导当事人一次性选对请求权基础与诉讼请求，避免释明失败导致反复起诉。

## A1 — 书中的应用 (Past Application)

**知识点清单（本书第三篇覆盖）**

- **第九章 合同关系**：请求权基础分析法（王泽鉴检视序列）；合同相对性为原则、突破为例外（实际施工人第43条第2款、工程质量连带、代位权第44条、案外人单方承诺/担保）；合同关系存在与否的三类判断；有权代表、表见代理、挂靠、指定分包下的合同相对人；多份合同能否一并诉讼。
- **第十章 合同内容**：合同形式（示范文本三部分、合同组成与解释顺序、鉴定方案也是合同载体）；10项内容审查要点（主体、项目名称、工程地点、争议处理与标的、工程内容、承包方式、造价组成与结算支付、工期与质量、违约与索赔、解除条款）；招投标合同审查（必须招标范围、阴阳合同）；内容矛盾/约定不明的解释次序；无合同案件内容查明。
- **第十一章 合同性质**：性质与案由的「三部曲」；名为供货安装/买卖/租赁/勘察/制作安装/劳务分包/内部承包实为他合同之辨；转包与挂靠、违法分包的联系区别；「建设工程」的边界；工程建设部分工作是否构成分包的五角度；性质查明对管辖、案由、诉讼请求的影响。
- **第十二章 合同效力**：效力审查的「主动、必须、不得有误」；无效十一种类型（无资质、借用资质、应招未招、中标无效、低于成本中标、无规划证、违法分包、转包、支解发包、任意压缩工期违反质量强标、通谋虚伪表示）；无效后的归责四类；无效的法律效果六项（缔约过失、不得继续履行或解除、违约金不适用、参照约定折价补偿、利息、损失赔偿）。

**关键案例揭示的裁判规则**

- **案例9-1**：合同无有效签章但原告能证明其实际施工、被告已付款77万元，可推定双方存在合同关系（书面合同是初步/直接证据，无书面时按举证责任转移由相对方解释）。
- **案例9-6**：项目经理以公司名义签约、用款申请单注明职务行为，合同相对人应认定为公司；原告坚持起诉个人、拒绝变更，释明失败后全案驳回，二审、再审均维持。
- **案例9-7**：项目经理持项目部印章签约租赁，构成表见代理，被代理人担责。
- **案例11-1 / 11-4 / 11-12 / 11-13**：中央空调供货安装=建设工程施工合同；脚手架「租赁」含人工施工=分包；劳务分包含乙供大型机械=违法分包；「内部承包」无劳动关系=挂靠——均按实质权利义务定性，不定名。
- **案例12-1 / 12-3 / 12-4**：超越资质等级=无效；主体结构分包=违法分包无效；备案合同与实际履行合同不一致、「名为指定分包实为支解发包」=通谋虚伪无效。
- **案例12-5**：B-36压型钢板属「屋面防水分部」而非钢结构——合同效力的认定常需依职权调取招投标文件、工程技术规范等证据。

完整案例与原文已存入 ima 知识库，需要时检索。

## A2 — 触发场景 (Future Trigger)

- 用户拿到一份工程合同或起诉材料，问「我到底该起诉谁」「对方和我有没有合同关系」「这笔钱该不该这个被告付」。
- 用户需要判断合同性质：「这份《设备买卖合同》到底算不算建设工程施工合同」「这算不算分包、会不会被认定无效」。
- 用户要做效力攻防：「这个合同是不是无效的」「我怎么主张无效/怎么保住它有效」。
- 用户面对招投标项目或阴阳合同：「中标合同和补充协议不一致，按哪份结算」。
- 用户被问「这个工程要不要招标、没招标合同还有效吗」「分包有没有经过发包人同意」。

**语言信号（原话示例）**：中：“帮我看看这个合同相对人是谁”“这是挂靠还是转包”“合同能不能认定无效”；英：“who is the counterparty”“is this contract void”“apparent agency”“black-and-white contract”。

**与相邻 skill 的区分**：
- 与 **dynamic-review**（动态审查五步）：本技能只审合同本身四要素；一旦涉及履约过程中的签证、付款、工期顺延、停工窝工等「合同履行」证据审查，属 dynamic-review。
- 与 **trial**（庭前与庭审）：本技能解决「合同怎么定性定效力」；具体到庭前会议、庭审发问、举证质证、释明应对的操作，属 trial。
- 与 **identification**（司法鉴定应对）：本技能不处理造价/质量/工期的鉴定思路与鉴定质证，仅在效力/内容审查需要时点到即止。

## E — 可执行步骤 (Execution)

1. **锁定合同关系**：核对有无书面合同/中标通知书及履行证据；确认签字人是有权代表、表见代理还是无权代理；排查挂靠、指定分包、多份合同能否一并诉。完成标准：能写出「合同相对人是谁 + 主张谁承担主付款责任、谁承担连带/补充责任」。
2. **补强合同内容**：按 10 项要点逐条摘出对我方有利/不利的约定；调取招投标文件、补充协议、签证单、结算文件；对矛盾条款按「解释次序 + 同顺位以后发生为准」确定立场。完成标准：形成一份「合同内容立场表」，每条约定注明我方依据与对方可能的反读。
3. **定性合同性质**：套「标的是否建设工程→是否建设工程合同→属哪一种」三部曲，明确我方主张的性质及其后果（案由、管辖、诉讼请求写法、是否需资质）。完成标准：能给出「我方定性 + 对方最可能的定性 + 各自后果」。
4. **效力攻防**：对照十一种无效类型逐一筛查，决定主动主张无效还是补强有效；预判法官释明点，先于法官向当事人释明风险并固定诉讼请求（确认之诉/给付之诉/变更之诉匹配效力状态）。完成标准：诉讼请求与合同效力结论自洽，无「按有效合同主张付款」与「按实际施工人突破相对性」并存的冲突。
5. **检索 ima 取原文**：当需要某知识点、案例的完整原文或具体法条序号核对时，调用 ima 知识库检索《解构与重塑》对应章节（第九章~第十二章）。

## B — 边界 (Boundary)

### 不要在以下情况使用
- 争议焦点是合同**履行过程**（签证、付款流水、工期顺延、停工窝工、竣工交付），而非合同本身四要素。
- 需要**司法鉴定**思路、造价/质量/工期专业判断。
- 庭前会议组织、庭审发问、举证质证、对法官释明的现场应对。
- 纯法条/词条释义查询（应路由到 cclr-pfcc）。

### 作者/时代局限（必写）
- 本书成书于 2021 年（第二版），所引法条与司法解释基于当时有效版本（《民法典》、《建设工程司法解释(一)》2021、原《建设工程司法解释(二)》、原《合同法》、《民法总则》、《招标投标法》等），部分条款序号与内容可能已被后续修正调整。办理案件前须核对现行有效法条与最新司法解释/裁判观点，禁止无脑套用书中的旧序号。

### 易混淆的邻近方法论
- 与 **dynamic-review**：静态审查审「合同」，动态审查审「履行」，两者同属法官的合同审查两大块，律师需按争议焦点切换。
- 与 **special-issues**：挂靠、转包、支解发包在本技能中只作为「定性/效力」的判据；一旦进入实际施工人权利、优先受偿权等专项实体问题，属 special-issues。
