# 《庭前准备与庭审应对》

## R — 原文 (Reading)

> "审判工作的重心应当前移，而非在质证后、开庭后再开始组织案件审理思路。"（第二篇·庭前准备）
> "无争议事实逐渐明朗、增多，争议焦点越发集中、具体……归纳无争议事实和明确争议焦点是法官应当尽可能采用的审理方法。"（第五篇·第二十三章）

---

## I — 方法论骨架 (Interpretation)

本书是法官视角，律师使用时要逐环镜像：**法官每一步审什么，我方就提前备什么、庭审怎么接。** 六个动作：

1. **立案前自查**（镜像"初步审查"）：法官收案第一件事是挑主体是否适格、诉讼请求是否明确可执行、请求权基础是否清楚、本院有无管辖/仲裁主管。律师起诉前先把这四关自查掉——诉请写规范（可执行、计算基数标准起止明确）、请求权基础先行锁定、主动核对管辖与仲裁条款，避免法官释明时我方被动。
2. **送达与保全博弈**（镜像"送达/保全"）：送达是法官摸被告态度的窗口，律师要预判被告会不会借管辖异议拖延；保全要先做必要性预判（被告有无履行能力、会否引发反诉保全战），担保要留够解封空间，别让保全变成两败俱伤的战场。
3. **庭前会议抢固定**（镜像"庭前会议"）：借证据交换把对我方有利的事实尽早"无争议化"，用已付款清单等简化方式把庞杂账目压缩，抢先逼法官明确"是否鉴定、谁申请、谁举证"。
4. **释明当信号**（镜像"释明"）：法官每一次释明都是心证的泄露。第一时间识别类型——是合同效力/法律关系/举证责任/鉴定风险？尤其"合同效力与主张不一致""合同相对人认定不一致"这类释明，要立即评估是否变更请求权基础，**不变更则后果自负**（本书多个案例败诉皆因拒不变更）。
5. **现场勘验抢主动**（镜像"现场勘验"）：主动申请或主动配合，带齐技术人员、测量器具、可视化材料，把勘验变成固定己方有利事实、现场清点争议工程量、甚至促成和解的机会。
6. **开庭与二次架构**（镜像"开庭审理/二次架构"）：预判法官会归纳哪些争议焦点，围绕焦点举证与辩论；紧盯对方证据突袭、反复推翻已确认事实、辩论阶段抛新主张，及时要求法官规制。

## A1 — 书中的应用 (Past Application)

**庭前准备知识点清单**（第二篇）：
- 诉讼材料初步审查三要件：主体适格（含分公司/项目部/筹建处/联合承包等特殊主体规则）、诉讼请求与请求权基础（预付/进度/结算/质保金要分性质、合同无效下主张路径）、基础材料是否齐备。
- 主管与管辖：仲裁条款优先（约定仲裁则法院无主管权）、专属管辖（建设工程施工/分包/装饰装修按不动产专属，勘察/设计除外；海事/铁路专门管辖）、级别管辖（2019 法发14号）。
- 送达六环节：原则（直接送达优先）、送达时沟通、引导、自认固定、调解、送达后反馈。
- 保全：必要性审查、保全中的实体判断（被告是否真正担责）、解除保全与财产置换、避免保全战、保全与管辖权衔接。
- 合议庭：承办法官为第一责任人、合议庭组成、实质性合议。

**审理程序知识点清单**（第五篇）：
- 庭前会议：程序性事项、起诉与答辩规范、举证（证据清单分门别类）、质证（三性+证明力）、补充证据、反诉处理、决定是否启动鉴定。
- 调查取证：当事人申请调查令（竣工验收报告、备案合同、款项明细、图纸等 8 类）、依职权调查、调查事项要明确。
- 释明：程序性释明、诉讼请求及法律问题释明、事实与证据释明、裁判释明；八大类须书面记录。
- 现场勘验：目的（熟悉现场/明确范围/厘清争议/推进鉴定）、必要性、时间（庭审前后/鉴定前后）、组织协调、勘验笔录。
- 开庭审理：排庭、阅卷并制定庭审提纲、开庭准备、法庭调查（陈述/举证质证/发问询问）、法庭辩论、最后意见、调解、当庭宣判。
- 庭审二次架构：无争议事实归纳与确认、争议焦点明确与修正、诉讼请求与请求权基础二次审查。

**关键案例裁判规则**：
- 案例4-1："责令双方结算"不能作为诉讼请求（不可执行）；原告仅凭施工合同主张全部欠款、未举证履约全过程，被释明补充否则败诉。
- 案例18-4：工程款证据证明力位阶——双方签字结算报告(95%) > 发包人委托审价报告(65-70%) > 月进度报表(60%) > 单方重新审价/同项目不同标段结算(50-60%)；应采证明力更高者。
- 案例20-4：法官释明"合同相对人是公司而非个人"与原告主张不一致，原告拒不变更请求权基础，全案驳回并承担诉讼费。
- 案例22-2：法庭询问环环相扣、每问含隐含目的，代理人须警惕勿轻易暴露不利事实（未通知工会、工会主席身份虚假）。
- 案例23-1：无争议事实经各方确认后可略过举证质证、直接作为裁判基础；缺席案件不适用。

## A2 — 触发场景 (Future Trigger)

- 客户案件即将进入庭前会议/证据交换/开庭，需要准备诉讼请求、证据清单与争议焦点预案。
- 法官当庭或庭前释明"合同效力/法律关系/合同相对人与你方主张不一致"，要求变更诉讼请求或请求权基础。
- 案件需现场勘验（质量/工程量/擅自使用争议），或对方申请勘验而我方需应对。
- 已付款、已完工量等账目庞杂，需要把争议压缩为清单、固定无争议事实。
- 对方借管辖异议拖延、证据突袭、反复推翻已确认事实、辩论阶段抛新主张，需要反制。

**语言信号**（用户原话，中英双写）：
- "庭前会议怎么准备？法官让我交换证据、归纳争议焦点" / "How to prepare for the pre-trial conference?"
- "法官释明我方合同无效/相对人不对，让我变更诉请，怎么应对" / "How to respond to judicial clarification?"
- "现场勘验要带什么、怎么利用它固定对我方有利的事实" / "How to use on-site inspection to my advantage?"
- "对方在辩论阶段突然交新证据、还推翻之前确认过的事实" / "Opponent raised new evidence during debate and retracted admitted facts"
- "保全怎么申请，会不会被对方反诉保全反制" / "How to handle preservation and counter-preservation"

**与相邻 skill 的区分**：
- 与 `jianshe-shenpan-ZhouLiming-static-review`：静态审查审"合同关系/内容/性质/效力"的实体判断；本技能是"程序驾驭与庭审应对"。问"合同有没有效、是不是黑白合同"→ static-review；问"庭前会议/释明/争议焦点怎么应对"→ 本技能。
- 与 `jianshe-shenpan-ZhouLiming-dynamic-review`：动态审查拆"履行/竣工/应付/已付/结算"九大账目；本技能是围绕这些账目"如何在程序里组织举证质证"。问"怎么算应付工程款、已付款"→ dynamic-review；问"质证时这些账目怎么简化、怎么固定无争议事实"→ 本技能。
- 与 `jianshe-shenpan-ZhouLiming-identification`：司法鉴定技能专管"是否鉴定、鉴定范围依据、鉴定意见质证"；本技能只在"庭前会议/庭审中是否启动鉴定"这个节点衔接，深入鉴定细节转 identification。

## E — 可执行步骤 (Execution)

1. **立案前四关自查**（完成标准：主体适格有据、诉请明确可执行且计算基数标准起止清楚、请求权基础锁定、管辖/仲裁主管已核对）。
2. **庭前会议预案**（完成标准：证据清单按"签约/效力/履行/竣工/应付/已付/结算/其他"分门别类并标页码与证明目的；预先拟定无争议事实与争议焦点清单；备好已付款对账表）。
3. **释明响应决策**（完成标准：对法官每次释明归类——合同效力/法律关系/举证责任/鉴定风险，24 小时内决定是否变更请求权基础并书面提交变更申请；若坚持不变更，向客户书面提示败诉风险）。
4. **现场勘验准备**（完成标准：申请或配合，带技术人员+测量器具（测距仪/卷尺/激光笔）+可视化材料（图纸/照片/模型），拟定需现场固定的事实与争议工程量清单）。
5. **庭审焦点攻防**（完成标准：预判法官争议焦点并逐条备证据与辩论点；对证据突袭/推翻已确认事实/辩论抛新主张，当庭要求法官按规则处理并记入笔录）。
6. **检索 ima 取原文**：当需要某知识点/案例的完整原文（如案例18-5庭前会议完整笔录、案例22-1庭审提纲、案例20-5三次释明）时，调用 ima 知识库检索《解构与重塑》对应章节。

## B — 边界 (Boundary)

### 不要在以下情况使用
- 只问合同效力、主体适格、黑白合同、工程总承包等**实体审查**，尚未进入程序应对——转 static-review。
- 只问履行/竣工/应付工程款/已付款/结算款的**账目计算**——转 dynamic-review。
- 只问工程造价/质量/工期/修复方案的**鉴定启动与质证细节**——转 identification。
- 纠纷主管已确定走仲裁、需处理仲裁条款效力或仲裁程序本身——转 arbitration。

### 作者/时代局限（必写）
- 本书成书于 2021 年（第二版），所引法条与司法解释基于当时有效版本（《民法典》、《建设工程司法解释(一)》2021、原《建设工程司法解释(二)》等），部分条款序号与内容可能已被后续修正调整。办理案件前须核对现行有效法条与最新司法解释/裁判观点，禁止无脑套用书中的旧序号（如书中所引原《建设工程司法解释》第26条实际施工人条款，现为《建设工程司法解释(一)》第43条）。

### 易混淆的邻近方法论
- 与 static-review 混淆：庭前会议里法官问"合同效力如何"时，既可能触发本技能（程序应对），也可能转 static-review（实体审查）——以用户意图为准：问"怎么应对"属本技能，问"合同到底有没有效"属 static-review。
- 与 identification 混淆：法官问"是否申请鉴定"是程序节点，属本技能；一旦进入"鉴定范围/依据/意见质证"即转 identification。
