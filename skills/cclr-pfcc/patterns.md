# 实务指引模式（Patterns）

> 本书"词条释义 + 实务指引"双结构的可复用分析套路。起草文书、分析案件、出具意见时按此推进。

## P1 主体适格 → 效力判断

**When to use**：接手建工纠纷，先判断当事人地位与合同效力。
**How**：
1. 识别我方/对方是发包人、承包人、分包人、实际施工人、挂靠人中的哪一类（第一章）。
2. 核资质：承包人有无资质、是否超越等级、是否挂靠/转包/违法分包（2.19–2.21、2.35–2.37）。
3. 核招标：是否必须招标、是否中标无效、有无黑白合同（2.2、2.13、2.11）。
4. 结论：合同有效 / 无效 → 决定结算路径（参照约定折价补偿 or 据实鉴定）。
**Trade-offs**：主体定性影响请求权基础（合同之诉 vs 突破相对性）。

## P2 黑白合同识别

**When to use**：同一工程存在多份合同/补充协议，需确定以哪份为准。
**How**：
1. 锁定中标合同（白合同）。
2. 比对实质性内容（工程范围、工期、质量、价款）是否背离。
3. 区分"违法背离"与"合法变更"：客观情况在招投标时难以预见（材料巨幅波动、规划调整）→ 变更有效；无客观变化 → 构成黑白合同（黑合同无效）。
**Trade-offs**：以白合同结算 vs 尊重双方真实意思/实际履行。

## P3 工程款结算链条

**When to use**：确定应付工程款数额。
**How**：
1. 定计价方式（固定总价/单价/可调价/成本加酬金）。
2. 调价：是否有基准日期/基准价格、当事人/非当事人原因的价格调整。
3. 计量与签证：工程量计量 + 签证是否有效。
4. 结算：以送审价为准 / 行政审计 / 无效合同结算 / 造价鉴定（必要时）。
5. 扣减：已付款、质量保证金、工期/质量违约金。
**Trade-offs**：按合同约定 vs 据实结算/鉴定。

## P4 优先受偿权主张

**When to use**：承包人追索工程款，需判断能否主张优先受偿权。
**How**：
1. 主体：是否为与发包人订立合同的承包人（含无效合同但质量合格的承包人）。
2. 标的：工程是否质量合格、是否不宜折价拍卖。
3. 范围：工程价款（人工费/材料费等）可优先；利息、违约金、损失不可优先。
4. 期限：自"应付工程价款之日"起 18 个月除斥期间内行使。
5. 顺位：优先于抵押权、普通债权；劣后于消费者购房人优先权。
**Trade-offs**：及时行使（除斥期间） vs 起算点争议（竣工/结算/解除/起诉）。

## P5 工期责任与顺延

**When to use**：判断工期延误责任、能否顺延、违约金。
**How**：
1. 定实际开工日、实际竣工日（司法解释第9条三情形）。
2. 核顺延事由（设计变更/不可抗力/不利物质条件/付款延误等）。
3. 关键线路分析：延误是否在关键线路、是否吃掉时差。
4. 共同延误：按过错与因果关系分配。
5. 索赔程序：意向通知 → 延续通知 → 索赔报告，注意索赔时限。
**Trade-offs**：程序失权 vs 实体顺延；工期违约金可请求调减。

## P6 质量责任与保修

**When to use**：处理工程质量争议、保修义务、修复费用。
**How**：
1. 定质量是否合格、是否缺陷/事故，有无验收程序瑕疵。
2. 责任主体：承包人/设计人/监理人/发包人（甲供材料、擅自使用）。
3. 是否竣工验收/擅自使用（擅自使用仅主体结构、地基基础除外）。
4. 保修：缺陷责任期 vs 保修期；保修范围与期限。
5. 修复费用：加固/修复方案的必要性、可行性、经济性合理性，及费用计算。
**Trade-offs**：返工/返修 vs 折价赔偿；鉴定必要性 vs 以鉴代审。
