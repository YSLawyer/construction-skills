# 第六章 工程质量及保修

> 词条 6.1–6.67（含子词条），共 71 个词条。覆盖工程类型、质量标准、验收程序、质量责任、保修义务与质量鉴定、修复费用。

## Core Idea

本章解决"工程质量是否合格、谁来担责、怎么验收、怎么保修、修多少钱"——质量是建工合同的生命线，也是"先收款后质保"与结算的前提。

## 核心实务要点

- **质量标准**：工程建设强制性标准（6.11）、工程质量验收标准（6.12）为底线；设计合理使用年限（6.10）内主体结构终身负责。
- **验收程序链**（6.32–6.47）：检验批 → 分项 → 分部 → 隐蔽工程 → 专项 → 预验收 → 竣工验收 → 竣工验收备案。隐蔽工程验收（6.35）是关键节点，未经隐蔽验收擅自覆盖可能不利。
- **未经竣工验收擅自使用（高频）**（6.48）：发包人擅自使用的，不得以使用部分质量不符合约定为由主张权利，但地基基础与主体结构质量除外。
- **质量责任划分**（6.21–6.27）：工程质量不合格/缺陷/通病/事故/偷工减料的认定与责任；设计变更（6.18）、工程变更（6.19）对质量的影响。
- **保修制度**（6.28/6.52–6.57）：缺陷责任期（6.28）与保修期（6.56）的区分；保修范围、保修义务、保修期限及延长；地基基础与主体结构按设计合理使用年限承担保修责任。
- **质量赔偿与鉴定**（6.58–6.60）：工程质量赔偿、工程质量鉴定（机构/分类/标准/程序/范围）、质量缺陷与行为的因果关系。
- **修复方案与费用**（6.61–6.67）：加固、修复方案的必要性/可行性/经济性合理性，及加固修复、维修、重置、拆除费用的确定。
