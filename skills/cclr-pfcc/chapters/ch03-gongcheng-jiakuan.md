# 第三章 工程价款

> 词条 3.1–3.86，共 86 个词条，是全书中词条最多、实务含量最高的一章。覆盖计价方式、价格调整、结算、造价鉴定与各类款项。

## Core Idea

本章解决"工程款怎么算、怎么调、怎么结、算多少"——从计价依据、签证计量，到结算审核、造价鉴定，再到进度款/结算款/违约金/利息等各类款项的认定。

## 核心实务要点

- **计价方式三分**：固定总价（3.13）、固定单价（3.14）、成本加酬金（3.15）；可调价（3.16）与价格调整条款（3.49 当事人原因 / 3.50 非当事人原因）决定风险分配。材料涨价（5.53、3.50）是调价高频争议。
- **基准日期/基准价格**（3.47/3.48）：新增词条，用于锚定价格调整与风险划分的时间点。
- **结算规则（高频）**：
  - **以送审价为准**（3.60）：发包人收到竣工结算文件后逾期不答复，可能视为认可送审价（《建设工程司法解释(一)》第21条）。
  - **以行政审计为准**（3.61）：仅当合同明确约定以审计结论为结算依据时才约束双方；否则不能以行政审计对抗已确认结算。
  - **无效合同价款结算**（3.56）：竣工验收合格的可参照合同约定折价补偿。
  - **高估冒算**（3.58）、**以鉴代审**（3.70）：鉴定不能替代裁判对合同约定的认定。
- **造价鉴定**（3.63–3.70）：申请、方法、未完工工程鉴定、鉴定意见质证、补充/重新鉴定、以鉴代审的边界。
- **签证与计量**（3.45 工程量计量、3.46 签证）：签证是工程量与价款变更的核心证据。
- **款项类型**（3.71–3.86）：预付款、进度款、结算款、质量保证金返还、已付款、垫资款、以房抵款、逾期利息损失、承包人可得利益、索赔款、分包工程款、工期/质量违约金、奖励金。
