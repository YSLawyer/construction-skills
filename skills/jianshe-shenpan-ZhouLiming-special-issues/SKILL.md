# 特殊疑难案件审理思路（优先受偿权·实际施工人·工程总承包）

## R — 原文 (Reading)

> "折价或拍卖、诉讼、仲裁才是行使优先权的有效方式，单纯的发函并非行使优先权的正确方式。"（第三十五章）"实际施工人限定为转包、违法分包、挂靠情形的承包人……不包括违法招投标导致合同无效情形下的中标人。"（第三十六章）工程总承包系承包人"对工程的质量、安全、工期和造价等全面负责的工程建设组织实施方式"。（第三十七章）

---

## I — 方法论骨架 (Interpretation)

法官面对三类疑难问题各有审查路径，律师应逐条镜像为「主张清单」或「抗辩清单」：

**优先受偿权（我方为承包人主张 / 我方为发包人或银行抗辩）**：主张方按五关逐项锁死——①主体适格（与发包人直接订立施工合同，或装饰装修承包人限增值部分）；②工程质量合格（合同无效不影响，竣工或分部分项验收/擅自使用可举证）；③范围=工程造价（定额/清单/固定价/成本加酬金，不含利息、违约金、损害赔偿金）；④期限=18 个月除斥期间、自「应当给付之日」起算；⑤主文写清权利人、义务人、金额、客体（项目正式名称）。抗辩方反向拆：否认主体、质疑质量、压缩范围、主张超期、揭穿恶意串通或调解确认的虚假诉讼（主动申请追加银行第三人）。绝不以「发函」当行使——只认折价、拍卖、诉讼、仲裁。

**实际施工人（我方为实际施工人突破 / 我方为发包人或总包抗辩）**：突破方四步走——先证明自己「是实际施工人」（转包/违法分包/挂靠），再锁定合同相对人（上家为第一被告），再举证质量合格+造价（否则主动主张合同无效并申请鉴定），最后查明发包人欠付范围。抗辩方四面围堵——否认其实际施工人身份、以有效合同/结算已清对抗、以仲裁条款或管辖约定阻断、把责任限缩在「发包人欠付范围」内并主张保证金等不应纳入。

**工程总承包（我方为总包方或分包/建设单位）**：先识别模式（EPC/DB/EP/PC/LSTK 及 PPP+EPC、F-EPC 衍生），再抓三条责任主线——清单漏项风险由总包人负担；总包人须持设计或施工资质、且作为「第二发包人」不得再违法分包主体部分（分包以一次为限，再分包违法无效）；其优先受偿权含设计费+采购费+施工费。据此定合同相对人、定效力、定责任链条。

## A1 — 书中的应用 (Past Application)

**第35章 优先受偿权——知识点清单**
1. 优先权具有担保物权属性、不公开公示，不能调解确认，法院应依职权追加银行等第三人（防虚假诉讼）。
2. 主体：与发包人订立施工合同的承包人可主张；勘察/设计/监理人不享有；实际施工人不能直接向发包人主张（能否代位行使优先权存在争议）；个人承包人可主张；装饰装修承包人限「增值部分」且发包人须为所有权人。
3. 客体排除：违章建筑、国家机关办公用房/军事建筑、公益设施、无法独立存在的附属工程（市政道路、桩基、玻璃幕墙等）。
4. 质量合格是前提；合同有效与否不影响优先权成立。
5. 范围=工程造价（直接费+间接费+利润+税金等），不含利息、违约金、损害赔偿金；警惕虚报造价以抬高优先权金额的恶意串通。
6. 期限：18 个月除斥期间，自应当给付之日起算；预付款、进度款不能主张；质保金可主张但时间在后；延长付款协议须审查是否恶意串通。
7. 主文=确认之诉，须载明权利人、义务人、金额、客体。

**关键案例揭示的裁判规则**
- 案例35-1：优先权不能以调解确认；发函/单方承诺非行使方式；法院主动追加银行第三人，识别《承诺函》《确认函》同时形成的虚假诉讼迹象，原告随后撤诉。
- 案例35-2：未经规划许可改建的「违章建筑」不具折价拍卖条件，优先权不予确认。

**第36章 实际施工人——知识点清单**
1. 概念限定为转包、违法分包、挂靠情形的承包人（单位或个人），不含违法招投标中标人、资质不符承包人。
2. 适用范围存分歧：从严（劳务分包+欠薪）vs 从宽（层层转包各层承包人），政策总体限缩。
3. 现实问题：无上位法依据、与仲裁/管辖冲突、滥诉与虚假诉讼、一案变多案的诉累。
4. 审理四步：①原告是否实际施工人；②基础法律关系明确（合同相对人为第一被告）；③质量合格+造价确定；④发包人在欠付范围内担责。

**关键案例揭示的裁判规则**
- 案例36-1：实际施工人（包清工钢筋班组）对发包人的责任范围不限于工程款，还包括利息、保证金等欠付款项；发包人与总包未结算不影响查明「应付款−已付款」后认定欠付范围。

**第37章 工程总承包——知识点清单**
1. 概念：承包人对质量、安全、工期、造价全面负责；模式含 EPC、DB、EP、PC、LSTK 及 PPP+EPC、F-EPC、EPC+O+M 衍生。
2. 清单漏项风险由工程总承包人负担。
3. 总包人须持设计或施工资质；施工总包不得分包主体施工、设计总包不得分包主体设计，分包以一次为限，再分包违法无效。
4. 总包人优先受偿权含设计费+采购费+施工费（区别于施工总承包仅施工造价）。

**关键案例揭示的裁判规则**
- 案例37-1：EPC 总包人将工程再分包，第三人再分包给施工方，属「分包后再分包」违法分包而无效；合同相对人按实际签约与付款主体认定，施工方不能越级向总包人主张。

**第38-40章（辅助）审理技巧要点**
- 相反陈述应对：柔性引导、释明风险、追问细节、顺势而为（案例38-1：表见代理+虚假增值税发票，被告被迫和解）。
- 推定规则：结算=「大结算」终局推定；明显变更推定发包人知情；未经验收擅自使用推定质量合格；分包关系与价款推定（以不超过总包从发包人结算价为限）。
- 反常行为找合理解释：发包人造价高于承包人、质保金提前支付、超付工程款，均可能是虚假诉讼/特殊原因。
- 价值判断：干了活就应拿钱、同一事项不重复给付、鼓励交易尽量不亏本、重视合理预见原则。
- 代理思路十问：你是谁告谁→工程性质所在地→是否结算→应付款→竣工否→已付款→合同有无→效力→鉴定→费用。

## A2 — 触发场景 (Future Trigger)

1. **优先受偿权主张/抗辩**：承包人在起诉状中主张「对工程折价/拍卖价款优先受偿」，或作为发包人、银行抵押权人收到对方优先权主张、发现调解书确认优先权。
2. **实际施工人突破合同相对性**：包工头/班组起诉发包人及多层主体连带付款，或发包人、总包被无合同关系的施工方起诉并被申请财产保全。
3. **工程总承包责任结构**：EPC/交钥匙项目中就合同相对人、再分包效力、清单漏项风险、优先权范围产生争议。
4. **虚假诉讼识别**：发承包双方「高度一致」请求确认优先权或虚高债权，需识别串通、追加银行第三人。
5. **疑难案件的推定与价值判断**：结算协议能否推翻、未经验收擅自使用、明显变更无签证、超付工程款等灰色地带。

**语言信号**（中英双写）："优先受偿权怎么主张/抗辩""实际施工人能不能直接告发包人""EPC 再分包有效吗""清单漏项谁担" / "claim priority of construction payment""does actual constructor break privity""EPC sub-subcontract validity"。

**与相邻 skill 的区分**：
- 与 `jianshe-shenpan-ZhouLiming-static-review`（静态审查四步：合同关系/内容/性质/效力）不同——本技能不处理合同效力与性质的常规认定，仅处理三类疑难问题；若用户只问「合同是否无效、性质是什么」应激活 static-review。
- 与 `jianshe-shenpan-ZhouLiming-dynamic-review`（动态审查五步：履行/竣工/应付款/已付款/结算）不同——若用户只问「工程造价、已付款、结算怎么审」应激活 dynamic-review，而非本技能。
- 与 `jianshe-shenpan-ZhouLiming-identification`（司法鉴定应对）不同——若用户只问「要不要鉴定、怎么质证鉴定意见」应激活 identification。

## E — 可执行步骤 (Execution)

1. **定位疑难类型并锁请求权基础**（完成标准：明确案件属「优先受偿权」「实际施工人」还是「工程总承包」哪一类，或数类交叉，写出我方的诉讼/抗辩目标）。
2. **按对应清单逐项过筛**（完成标准：优先权走「主体→质量→范围→期限→主文」五关；实际施工人走「身份→相对人→质量造价→发包人欠付」四步；工程总承包走「模式→漏项风险→资质→再分包→优先权范围」三线，逐项给出支持/抗辩要点与证据指向）。
3. **预判对方抗辩并反向拆解**（完成标准：站在法官审查路径的镜像，列出对方最可能攻击点——如实际施工人身份、超期、恶意串通、仲裁条款——并给出回应或阻断方案）。
4. **识别虚假诉讼/反常行为**（完成标准：核对有无「发包人造价高于承包人」「质保金提前支付」「调解确认优先权」「发函代替行使」等反常信号，决定是否申请追加第三人、调查取证）。
5. **检索 ima 取原文**：当需要某知识点/案例（如案例35-1、36-1、37-1）的完整原文与裁判说理时，调用 ima 知识库检索《解构与重塑》第九篇对应章节。

## B — 边界 (Boundary)

### 不要在以下情况使用
- 用户只需常规认定合同效力、合同性质、合同关系——用 `jianshe-shenpan-ZhouLiming-static-review`。
- 用户只问工程造价、已付款、结算、竣工等动态审查——用 `jianshe-shenpan-ZhouLiming-dynamic-review`。
- 用户只问司法鉴定的启动、质证、与鉴定人沟通——用 `jianshe-shenpan-ZhouLiming-identification`。
- 纯仲裁程序问题（仲裁协议效力、仲裁请求设计）——用 `jianshe-shenpan-ZhouLiming-arbitration`。

### 作者/时代局限（必写）
- 本书成书于 2021 年（第二版），所引法条与司法解释基于当时有效版本（《民法典》、《建设工程司法解释(一)》2021、原《建设工程司法解释(二)》、已废止的法释[2002]16号批复等）。优先权期限、主体、范围等规则应以现行《最高人民法院关于审理建设工程施工合同纠纷案件适用法律问题的解释（一）》（2021）及最新裁判观点为准；「18 个月」等数字、原批复「6 个月」等旧规不得无脑套用，办理案件前须核对现行有效法条与最新司法解释。

### 易混淆的邻近方法论
- 与 `jianshe-shenpan-ZhouLiming-dynamic-review`：动态审查处理「应付款（造价）」，而优先权「范围=工程造价」仅是造价确定后的权利范围判断，二者易混，本技能聚焦权利本身而非造价计算。
- 与 `jianshe-shenpan-ZhouLiming-identification`：实际施工人/优先权案件中常需造价、质量鉴定，但本技能负责「是否构成实际施工人、是否享有优先权」的法律判断，鉴定程序本身归 identification。
- 与 `jianshe-hetong-quanshu`：词条全书提供「黑白合同、合同效力」等词条释义，本技能提供三类疑难问题的审理/代理思路，可组合查询。
