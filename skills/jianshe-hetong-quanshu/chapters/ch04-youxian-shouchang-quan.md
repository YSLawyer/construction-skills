# 第四章 建设工程价款优先受偿权

> 词条 4.1–4.12（含子词条），共 26 个词条。系统性拆解《民法典》第807条、《建设工程司法解释(一)》第35–42条的优先受偿权制度。

## Core Idea

优先受偿权是对债权平等原则的突破，须严格限制行使。本章解决"谁有优先权、对什么标的、什么范围、什么时候行使、与其他权利的顺位"。

## 核心实务要点

- **性质与主体**（4.1/4.2）：优先受偿权为法定担保物权性权利；权利主体=与发包人订立施工合同的承包人（施工承包人、工程总承包人），无效合同承包人（工程质量合格）亦可主张（4.2.3）。
- **行使对象**（4.3）：仅限发包人（及受让项目、非发包人所有权人等特殊情形），不能对抗消费者购房人。
- **标的物**（4.6）：质量合格的工程；不宜折价、拍卖的工程（如学校、医院等公益设施）不得优先受偿；建设用地使用权本身不属于标的，但工程与土地使用权一并处分。
- **范围**（4.7）：可优先受偿的=工程价款（含人工费、材料费等实际支出）；有争议的（利润、垫资利息）；不可优先受偿的（逾期利息、违约金、损失赔偿等）。
- **放弃与限制**（4.5）：放弃不得损害建筑工人工资权益，否则无效。
- **行使期限（关键）**（4.11）：《建设工程司法解释(一)》第41条——合理期限内行使，**最长不超过18个月**（原6个月延长至18个月），自"发包人应当给付工程价款之日"起算；性质为**除斥期间**，不中止、不中断、不延长。起算点有分歧：竣工之日 / 交付使用之日 / 结算确定之日 / 约定竣工之日（未竣工）/ 合同解除或终止之日 / 应付款日 / 起诉或仲裁之日。
- **行使顺位（高频）**（4.12）：优先受偿权 > 抵押权 > 普通债权（4.12.1）；但**消费者购房人的优先权优于工程价款优先受偿权**（4.12.2，已付全部或大部分购房款的消费者）。
