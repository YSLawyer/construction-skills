## Core Frameworks & Mental Models

**全书方法论：词条释义 + 实务指引 双结构。** 每个词条按「基本解读 → 实务指引（分点）→ 涉及纠纷的不同裁判观点 → 相关法条/案例」展开。用法：先看"基本解读"定概念，再看"实务指引"找操作规则，最后看"裁判观点分歧"定位风险点。

**六大主题地图（章）**：
1. **相关主体**（ch01）—— 先定性"谁是谁"，再谈责任。
2. **合同效力**（ch02）—— 先判"合同有效吗、以哪份结算"，是万法之门。
3. **工程价款**（ch03）—— 算账：计价/调价/结算/鉴定/各类款项。
4. **优先受偿权**（ch04）—— 保收款的法定优先权，严格限权。
5. **工期延误·索赔·违约**（ch05）—— 第二战场：工期责任与损失量化。
6. **工程质量及保修**（ch06）—— 生命线：验收、责任、保修、修复。

**高频决策规则（详见 cheatsheet）**：
- **黑白合同**：以中标合同定权利义务；无客观变化而变更实质性内容 = 黑合同无效；有难以预见变化 = 合法变更。
- **无效合同结算**：竣工验收合格 → 参照约定折价补偿；不合格 → 修复后合格方可，仍不合格一般不付。
- **优先受偿权**：18 个月除斥期间，自"应付工程价款之日"起算；范围=工程价款（利息/违约金/损失除外）；顺位=劣后于消费者购房人、优先于抵押权。
- **以送审价为准**：发包人逾期不答复结算文件 → 视为认可送审价。
- **工期顺延**：只看关键线路延误；时差内延误不顺延；逾期索赔可能失权。
- **擅自使用**：发包人擅自使用的，不得就使用部分主张质量不符（地基基础、主体结构除外）。

**思考方式（mental models）**：
- 建工纠纷三问：**合同有效吗 → 该给多少钱 → 谁担什么责（质量/工期）**。
- 把每个词条当"请求权要件的构成要素"拆解，而非孤立法条。
- 裁判观点分歧处，务必检索最新类案与现行有效司法解释（本书基于 2021 版规范，起草前须核对现行法条）。
