# 专题2：建设工程施工合同的效力判断规则

> 来源：邬砚《规则重构：建设工程施工合同纠纷裁判路径总梳理》（法律出版社 2024.02 第1版）

## 2.1 建设工程施工合同的成立
- **裁判规则8**：建设工程施工合同是要式合同，以书面形式为成立要件；发承包未采书面形式但已实际施工，依履行治愈规则认定合同成立（仅治愈形式瑕疵，不治愈效力瑕疵）。
  - 典型案例8：中铁二十四局集团有限公司与新疆甘泉堡神信物流有限责任公司建设工程施工合同纠纷案（未签书面合同但已部分施工并接受成果，依实际履行认定合同成立）
- **裁判规则9**：施工合同所要求的书面形式不限于合同书，信件、电报、电传、传真、投标文件、中标通知书等有形表现所载内容的形式，均构成合同的书面形式。

## 2.2 承包人资质对建设工程施工合同效力的影响
- **裁判规则10**：现行法对建筑业企业资质的要求指向施工方，故发包人、转包合同的转发包人、分包合同的分发包人不具备资质的，不影响施工合同效力。
  - 典型案例10：青海盛邦建设集团有限公司与海东市平安区司法局、西宁闽德房地产开发有限公司建设工程施工合同纠纷案（司法局作为发包人无房地产开发资质，不影响其与承包人签订的施工合同效力）
- **裁判规则11**：工程总承包范围包括设计与施工的，工程总承包人或联合承包体应同时具备与工程规模相适应的设计资质与施工资质，否则工程总承包合同无效。
- **裁判规则12**：施工总承包人（除具备施工综合资质者外）须既符合资质类别又满足资质等级要求，否则所签施工合同无效。
- **裁判规则13**：专业工程的承包人须既符合资质类别又满足资质等级要求，否则所签专业承包合同无效。
- **裁判规则14**：专业作业（劳务）资质不分类别与等级，劳务分包合同的施工方具备专业作业资质即可承接任何专业作业工程。
- **裁判规则15**：三层以下农村住宅属"农民自建低层住宅"不适用《建筑法》，不要求承包人具备相应资质，但三层（含三层）以上农村住宅除外。
- **裁判规则16**：小型房屋建筑工程（工程投资额30万元以下或建筑面积300平方米以下，或地方有特别规定从其规定）不要求承包人具备相应施工资质。
- **裁判规则17**：公共建筑装饰装修工程、工业建筑装饰装修工程、成品房批量装修工程的承包人应具备相应建筑装修装饰工程专业承包资质，否则装饰装修合同无效。
- **裁判规则18**：住宅室内装饰装修工程属于建设工程，但基于施工内容与工程规模，承包人无须具备建筑装修装饰工程专业承包资质。
- **裁判规则19**：施工合同因承包人缺资质本应无效的，可因承包人在工程竣工或停建前取得相应资质而补正效力，补正时点限于竣工（或停止建设、交付）之前。
- **裁判规则20**：签约时具备资质、嗣后因资质被吊销或降级等不再满足要求的，施工合同仍有效，但因承包人欠缺履行能力的应予解除。

## 2.3 不同经营模式对建设工程施工合同效力的影响
- **裁判规则21**：发包人将单位工程肢解成若干部分发包给数个承包人的，构成肢解发包，所签数个施工合同均无效（单位工程为肢解发包与平行发包的分界线）。
- **裁判规则22**：工程总承包人将设计或施工转交第三人完成，不认定为转包或违法分包，但将设计与施工全部转交第三人完成的除外。
- **裁判规则23**：承包人将承包的全部工程转交第三人，或将全部工程肢解后以分包名义分别转交的，构成转包，所签转包合同无效。
  - 典型案例23：江苏南通三建集团股份有限公司与南京市第十建筑工程有限公司等建设工程施工合同纠纷案（总包人将全部工程肢解后以分包名义转包，分包合同无效）
- **裁判规则24**：经发包人同意，承包人可将其合同权利义务概括转移给有相应资质的第三人，但经招投标程序订立的施工合同除外（中标后转让无效）。
- **裁判规则25**：母公司将承接的工程交由具有独立法人资格的子公司施工，因母子为不同法人，构成转包，所签施工合同无效。
- **裁判规则26**：不同建筑企业组成联合体承揽工程后由联合体一方单独承建的，视为转包。
- **裁判规则27**：承包人将承包工程中的部分工程依法分包（专业分包或劳务分包）的，所签分包合同有效。
- **裁判规则28**：专业分包须满足：分包人具备相应专业资质、分包内容限于主体结构以外（钢结构工程原除外，现已并入总包资质），否则分包合同无效。
- **裁判规则29**：专业分包未取得发包人同意或认可的，不影响专业分包合同效力，但发包人有权追究承包人违约责任。
- **裁判规则30**：劳务分包须满足：分包人具备专业作业资质、分包内容限于劳务作业（不涉及主要建材、大中型施工机械设备、主要周转材料），否则无效；劳务分包无须经发包人同意。
- **裁判规则31**：分包人将其承包工程再分包的，再分包合同无效；但专业分包单位将其专业工程中的劳务部分再分包的除外（有效）。
- **裁判规则32**：指定分包违反现行法，承包人有权拒绝发包人指定，但不得以此主张指定分包约定及所签分包合同无效。
- **裁判规则33**：承包人通过内部承包将工程交下属分支机构或职工组织施工，由此签订的内部承包合同有效（属经营自主权）。
- **裁判规则34**：内部承包须满足：内部承包人为承包人内设机构或职工、承包人对内部承包人有管理权、双方共担经营风险，否则内部承包合同无效。
- **裁判规则35**：约定将工程交下属机构或职工自主经营、自负盈亏的，应认定为名为内部承包、实为转包（或违法分包）。
- **裁判规则36**：具有诉讼主体资格的内部承包人，可依据内部承包合同以自身名义向发包人或承包人主张工程款债权（主流司法观点）。

## 2.4 招投标程序对建设工程施工合同效力的影响
- **裁判规则37**：工程是否属于必须招投标，应严格依《必须招标的工程项目规定》《必须招标的基础设施和公用事业项目范围规定》确定，不得扩大解释。
  - 典型案例37：江苏省苏中建设集团股份有限公司、包头市恒源房地产开发有限责任公司建设工程施工合同纠纷案（纯民营资本且不涉及公共利益的工程，一般不应认定为必须招标）
- **裁判规则38**：依法必须招投标的工程，建设行政主管部门允许直接发包属越权行政行为，由此签订的施工合同无效。
- **裁判规则39**：民间资本投资的工程项目，即使符合强制招投标规定，也应由投资主体自行决定是否招标。
- **裁判规则40**：符合规定的PPP项目，合作方依法能够自行建设的，可以不进行招标。
- **裁判规则41**：法定招标方式仅限公开招标和邀请招标，议标、竞争性谈判等方式均不属于招投标范畴（据此签合同可能无效）。
- **裁判规则42**：依法应公开招标的工程采取邀请招标确定中标人的，因招标形式不合法，中标无效。
- **裁判规则43**：招标文件与投标文件不一致的，应以投标文件（要约）为准。
- **裁判规则44**：中标通知书应符合镜像规则，若与投标文件实质性内容不一致，中标通知书无效，所签施工合同亦无效。
- **裁判规则45**：中标通知书到达之日发承包双方即成立施工合同关系，其后签订的书面合同系对已成立合同关系的确认、细化与补充。
  - 典型案例45：江苏中南建筑产业集团有限责任公司与潜江市兴城投资开发有限公司建设工程施工合同纠纷案（中标通知书到达即承诺生效、合同成立，招标文件与投标文件构成合同文本）
- **裁判规则46**：中标后签订的书面合同与招投标文件、中标通知书载明的实质性内容不一致的，应以招投标文件和中标通知书确定的承包条件为准。
- **裁判规则47**：《招标投标法》限定的实质性内容包括合同标的、价款、质量、工期、投标方案等足以影响其他竞标人能否中标或以何种条件中标的内容。
- **裁判规则48**：依法必须招投标的工程虽经招投标，但中标被认定无效的，其后签订的施工合同相应无效。
- **裁判规则49**：招投标前发承包双方就投标价格、投标方案等实质性内容谈判，其后承包人中标构成"明招暗定"（先定后招），中标无效。
- **裁判规则50**：中标价是否低于成本价，应按中标人完成工程的个别成本判断，并由中标人承担其个别成本的证明责任。
- **裁判规则51**：必须招投标工程中标后工程范围重大变更，或变更致超越中标人施工资质的，应当重新进行招投标。
- **裁判规则52**：非强制招投标工程先私下签合同再自愿招投标的，标前合同效力不受招投标程序影响（通常有效），中标合同效力按是否真实意思表示分别判定。

## 2.5 建设审批手续对建设工程施工合同效力的影响
- **裁判规则53**：应办建设工程规划审批手续的工程未取得规划审批手续的，施工合同因标的物（违法建筑）违法而无效（发包人在起诉前取得的除外）。
  - 典型案例53：中铁十五局集团第五工程有限公司、乌江铁路建设运营有限公司建设工程合同纠纷案（未取得建设用地规划许可证、建设工程规划许可证，施工合同因违反强制性规定无效）
- **裁判规则54**：规划审批手续因工程位于城市/镇规划区（建设用地规划许可证+建设工程规划许可证）或乡/村庄规划区（乡村建设规划许可证）而不同。
- **裁判规则55**：基于办证先后顺序（取得工程规划许可证即推定已办用地规划许可），判断合同效力时只需审查是否取得建设工程规划许可证。
- **裁判规则56**：应办而未办建设工程规划许可证的工程，围绕该工程签订的总包、分包、装饰装修等所有施工性质的合同，均应归于无效。
- **裁判规则57**：已取得规划许可证但施工范围超越许可证规模的，合同无效；合法部分与违法部分可区分的，仅违法部分无效。
- **裁判规则58**：未取得规划许可证但承包人有证据证明发包人能够办理而未办理的，准用"恶意阻止条件成就视为条件成就"规则，认定施工合同有效。
- **裁判规则59**：已取得的建设工程规划许可证失效（到期或被撤销）的，基于行政行为确定力，不影响失效前签订的施工合同效力。
- **裁判规则60**：因未取得规划许可证无效的施工合同，效力可因嗣后取得规划许可证补正，补正时点限于起诉前。
- **裁判规则61**：工程总承包合同含工程设计，不因未取得建设工程规划许可证而无效，但未取得建设用地规划审批手续的除外。
- **裁判规则62**：施工合同因未取得规划许可证无效，其损失赔偿等争议与违法建筑有牵连但不指向建筑本身，不适用行政处理前置原则。
- **裁判规则63**：建设工程未取得土地使用权证的，不影响施工合同效力（但常致无法办规划许可证而间接无效）。
- **裁判规则64**：施工许可证是行政主管部门对施工行为的行政管理措施，发包人未依法领取的不影响施工合同效力（属管理性规定）。
- **裁判规则65**：依法应办安全生产许可证的工程，承包人未取得安全生产许可证的不影响施工合同效力（属管理性规定）。

## 2.6 建设工程施工合同无效对相关协议效力的影响
- **裁判规则66**：结算协议作为清理既存债权债务达成的协议，效力独立于施工合同，但背离有效中标合同而按"黑合同"达成的结算协议除外。
  - 典型案例66：薛理杰、陈强与重庆交通建设（集团）有限责任公司等建设工程施工合同纠纷案（无效的劳务协作/转包协议之外，《退场清算协议》效力独立，应作为结算依据）
- **裁判规则67**：发承包双方达成的以房屋抵偿工程款的协议属债务清偿协议，效力独立于施工合同。
- **裁判规则68**：垫资协议属于施工合同的组成部分，效力不具独立性，施工合同无效则垫资协议相应无效。
- **裁判规则69**：基于合同相对性，同一链条上不同环节的施工合同效力应独立评价，彼此互不影响。
