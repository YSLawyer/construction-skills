# 裁判路径模式（Patterns）

> 本书"规则重构"的核心是可复用的裁判分析路径。分析建工案件、组织攻防、起草文书时按此推进；具体规则编号见各章索引。
> 来源：邬砚《规则重构：建设工程施工合同纠纷裁判路径总梳理》（法律出版社 2024.02 第1版）｜许可：CC BY-NC 4.0（禁止商用）。

## P1 合同性质与效力判断

**When to use**：接手建工纠纷，先定性合同性质与效力。
**How**：
1. 识别系争协议是否属于建设工程施工合同（专题1，规则1–7），排除承揽/劳务/合作开发等。
2. 核资质：承包人有无资质、是否超越等级（专题2）。
3. 核招标：是否必须招标、是否中标无效、有无黑白合同（专题2、专题8）。
4. 核违法形态：转包/违法分包/挂靠（专题2、专题11）。
5. 结论：有效 / 无效 → 决定结算路径（约定结算 or 参照折价补偿 or 据实鉴定）。
**Trade-offs**：效力认定影响请求权基础（合同之诉 vs 突破相对性 vs 折价补偿）。

## P2 工程款结算路径选择

**When to use**：确定应付工程款数额。
**How**（按优先级穷尽）：
1. 自行结算（专题5.1）：当事人已核对确认 → 直接采信。
2. 审计结算（专题5.2）：仅合同明确约定以审计为准时适用。
3. 拟制结算（专题5.3，规则186–195）：发包人逾期答复 → 视为认可送审价。
4. 裁判结算（专题5.4，规则196–202）：无法达成一致 → 法院/仲裁据实认定。
5. 无效合同参照结算（专题5.5，规则213）：参照合同约定折价补偿。
6. 司法鉴定（专题5.6，规则222–225）：最后途径，不得"以鉴代审"。
**Trade-offs**：尊重意思自治（约定/送审价）vs 据实结算/鉴定；鉴定不能替代对合同内容的认定。

## P3 优先受偿权主张

**When to use**：承包人追索工程款，需判断能否主张优先受偿权。
**How**：
1. 主体：与发包人订立合同的承包人（含无效但质量合格的承包人）（专题9）。
2. 标的：工程是否质量合格、是否不宜折价拍卖。
3. 范围：工程价款（人工费/材料费等）可优先；利息、违约金、损失不可优先。
4. 期限：自"应付工程价款之日"起 18 个月除斥期间内行使（不中止/中断/延长）。
5. 顺位：优先于抵押权、普通债权；劣后于消费者购房人超级优先权。
**Trade-offs**：及时行使（除斥期间）vs 起算点争议（竣工/结算/解除/起诉）。

## P4 实际施工人 / 挂靠路径

**When to use**：涉及借用资质、转包/违法分包链条中的权利主张。
**How**：
1. 认定实际施工人（专题10，规则393–422）：是否在无效合同关系中实际组织施工、投入资金人力。
2. 突破相对性：在发包人欠付工程款范围内向发包人主张（专题10）。
3. 挂靠识别与界分（专题11，规则423–442）：挂靠 vs 转包；出借资质方对外责任；工程款归属。
**Trade-offs**：保护实际施工人利益 vs 维护合同相对性与资质管理秩序。

## P5 黑白合同路径

**When to use**：同一工程存在多份合同/补充协议，需确定以哪份结算。
**How**（专题8，规则302–328）：
1. 锁定中标合同（白合同）。
2. 比对实质性内容（工程范围、工期、质量、价款）是否背离。
3. 区分"违法背离"与"合法变更"：招投标时难以预见的客观变化（材料巨幅波动、规划调整）而协商变更 → 有效；无客观变化 → 黑合同无效，以白合同为准。
**Trade-offs**：以白合同结算 vs 尊重真实意思/实际履行（中标合同无效时改"参照实际履行"）。

## P6 主管与管辖路径

**When to use**：立案阶段确定能否受理、由谁管辖。
**How**（专题12，规则443–456）：
1. 受案范围：是否属建工合同纠纷（含优先受偿权、实际施工人等衍生纠纷）。
2. 专属管辖：建工纠纷由工程所在地法院专属管辖。
3. 仲裁条款：有效仲裁条款排除诉讼；审查仲裁机构约定是否明确。
4. 诉讼主体：发包人、承包人、实际施工人、被挂靠人的列明与追加。
**Trade-offs**：诉讼便捷 vs 仲裁一裁终局；管辖异议的时机与后果。
