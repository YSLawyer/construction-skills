# 司法鉴定应对（造价·质量·工期）

## R — 原文 (Reading)
> "法院审理建设工程合同纠纷案件最大的问题，即为过于依赖鉴定，'以鉴代审'备受诟病。"（第七篇 司法鉴定 第29章 工程造价鉴定）
>
> "从比例上看……工程造价鉴定最为常见，约占据85%左右，工程质量鉴定10%左右，工期鉴定甚至不到5%……（1）质量鉴定先行……（2）造价鉴定是主体……（3）关于工期鉴定。多数情况下，工期鉴定可以在工程造价鉴定结束后再启动。"（第28章 三大鉴定的关系）

---

## I — 方法论骨架 (Interpretation)
法官审理鉴定，本质是一条"该不该鉴 → 鉴什么 → 用什么鉴 → 盯意见 → 按序布局"的控制链。律师要把每一步反转成可执行的攻防动作：

1. **先问"该不该鉴"**：法官启动前要过必要性、关联性、可行性、最小化四关。我方想阻止鉴定，就主动举证"已有结算协议、自认与确认、固定总价无变更、默示条款、第三方审价/结算报告"；我方需要鉴定定案，就主动申请并预缴费用，抢占启动权，避免对方反悔或举证不能反噬我方。

2. **锁定"鉴什么"**：鉴定范围、标准、方法、变量（计价方法、下浮率、调差期间、取样范围）必须在鉴定准备会和《鉴定方案》里书面固定。防止鉴定人"以鉴代审"扩大范围或替法官做法律判断。

3. **守住"用什么鉴"**：鉴定材料未质证不得作为鉴定依据（《建设工程司法解释(一)》第33、34条）。凡未质证材料入鉴定，立即提出异议，要求补充质证，否则主张该部分意见不得定案。

4. **全程"盯意见"**：征求意见稿（7日内）→《异议书》→正式稿→鉴定人出庭→专家辅助人。异议书要"先无争议后有争议、抓大放小"，金额大、依据足的放前面。

5. **按序"布鉴定"**：质量先行可阻却造价；造价是主体；工期最后。作为承包人对抗工期违约，用关键线路法/共同延误主张顺延，把举证不能后果推向对方。

## A1 — 书中的应用 (Past Application)
**知识点清单**
- 鉴定意见的法律属性：法定证据之一、形成于诉讼中、多为间接证据、无天然高证明力；结算协议证明力高于鉴定意见。
- 三大鉴定关系：质量先行、造价主体、工期最后。
- 鉴定不能三情形：鉴定依据严重不足、客观条件不具备、鉴定人不具备相应资质（由举证方承担后果）。
- 造价鉴定启动审查四原则（必要性/关联性/可行性/最小化）；应不予启动的七种情形（协商一致合意、自认确认、固定总价无变更、已有证据可直接计算、默示条款、第三方审价/结算报告、质量抗辩成功）。
- 造价鉴定方法确定原则：委托至上、约定优先、尊重新约定、未约定按通行标准、贯穿调解、综合考量准确可行安全经济、考虑过错与公平。
- 鉴定意见书流程：征求意见稿→异议书→正式稿→补充鉴定；"逾期视为放弃"一般有效但有合理理由可宽限。
- 质量缺陷三分（缺陷/通病/事故）+ 五个维度（结构安全性/功能适用性/耐久性/环境健康/外观）+ 显性隐性之分。
- 质量案件请求权基础七种情形（决定谁举证、谁申请鉴定）。
- 质量鉴定无征求意见稿；鉴定意见不应写"合格/不合格"，而应写是否符合设计文件与技术标准。
- 修复方案：原设计单位独特地位、属咨询意见而非司法鉴定、修复造价按鉴定时定额价取费。
- 工期四概念（约定/实际/定额/合理）+ 工期鉴定五种方法（实际与计划对比、计划影响、时间影响、影响事件剔除、视窗分析）。

**关键案例揭示的裁判规则**
- 案例29-1（虚拟）：一审不申请鉴定的释明风险——可能被二审发回重审，律师须在一审尽早决定并预缴费用。
- 案例29-6（青海方升/隆豪）：固定单价合同中途解约，最高法改定额计价遭本书批评——主张按"已完工比例×约定单价"而非定额。
- 案例29-7（龙纹门窗）：隐藏在下浮率里的计价原则应予尊重，合同无效仍参照适用。
- 案例29-8（深腾劳务）：未约定又无法鉴定时，参照同类或相似标准确定。
- 案例32-1（宏辰/百帆）：质量鉴定"谁主张谁举证"；鉴定范围与取样数量可在准备会协商缩减。
- 案例33-1（无畏汽车）：渗漏修复方案由原设计单位出具，鉴定工作会预设责任比例（同等各50%、主次70%/30%）。
- 案例33-3（月天电力）：地坪下沉主因系设计缺陷，鉴定须区分原因力，责任归向设计方而非施工方。
- 案例34-1（克源/陆建）：工期鉴定因证据不足只能用影响事件分析报告，可顺延371天；承包人拒不交付竣工资料另行计入工期违约。
- 案例34-2（仁置/工务局）：可顺延天数须核对关键线路、剔除重叠，可直接计算的顺延无须鉴定。

## A2 — 触发场景 (Future Trigger)
- 客户问"这笔工程款要不要申请造价鉴定""对方申请鉴定，我方能阻止吗/怎么应对"，或已收到鉴定征求意见稿/正式稿需要提异议。
- 发包人以质量缺陷拒付或反诉，我方（承包人/发包人任一方）需决定是否启动质量鉴定、锁定鉴定范围与责任比例。
- 工期违约或工期顺延争议，涉及关键线路、共同延误、停窝工损失、赶工费。
- 质量修复方案（原设计单位出具 or 司法鉴定）及修复造价争议，涉及替代履行、修复范围固定。
- 语言信号（中）："要不要鉴定""鉴定范围怎么定""鉴定意见怎么质证""异议书怎么写""工期能顺延几天""修复费用谁承担"。（英）："do we need an appraisal""challenge the expert report""extension of time""delay analysis""repair cost appraisal"。

**与相邻 skill 的区分**
- `jianshe-shenpan-ZhouLiming-dynamic-review`：管履约事实（签证是否有效、付款是否构成默示条款、竣工验收）；本技能只管"鉴定程序"（是否鉴、怎么鉴、怎么质证）。
- `jianshe-shenpan-ZhouLiming-trial`：管庭前会议与庭审通用程序（举证质证、鉴定人出庭的流程安排）；本技能专攻鉴定事项的确定与鉴定意见的专业质证。
- `jianshe-shenpan-ZhouLiming-special-issues`：管优先受偿权顺位、实际施工人、工程总承包等特殊主体/权利问题；本技能不处理这些实体问题本身。

## E — 可执行步骤 (Execution)
1. **定策：判断要不要鉴**（完成标准：对照四原则与七种不启动情形，明确我方申请/阻止/依职权鉴定的立场，并预判鉴定不能与举证不能的后果归属）。
2. **锁定：确定鉴定范围、事项与变量**（完成标准：在鉴定准备会与《鉴定方案》中书面固定计价方法、下浮率、调差期间、取样范围与责任比例预设，排除无争议项）。
3. **质证：材料质证 → 异议书 → 出庭**（完成标准：鉴定材料全部经质证；7日内提交结构清晰、抓大放小的《异议书》；必要时申请鉴定人出庭并申请专家辅助人对质）。
4. **排序：三大鉴定按序布局**（完成标准：质量先行可阻却造价、造价为主体、工期最后；工期争议用关键线路法主张顺延，直接可算的顺延不申请鉴定）。
5. **检索 ima 取原文**：当需要某知识点、案例或完整法条原文时，调用 ima 知识库检索《解构与重塑》对应章节（第28-34章）获取原文。

## B — 边界 (Boundary)
### 不要在以下情况使用
- 只审查合同条款效力、计价约定、招投标文件效力本身，尚未进入鉴定程序。
- 履约过程中签证、付款、竣工验收、工期签证等事实认定问题（属动态审查）。
- 优先受偿权顺位、实际施工人主体资格、工程总承包模式等特殊实体问题。
- 纯仲裁程序的组庭、程序规则、仲裁条款效力问题。

### 作者/时代局限（必写）
- 本书成书于 2021 年（第二版），所引法条与司法解释基于当时有效版本（《民法典》、《建设工程司法解释(一)》2021、原《建设工程司法解释(二)》、2019《证据规定》、2007《民事诉讼法》鉴定条文序号等），部分条款序号与内容可能已被后续修正调整。办理案件前须核对现行有效法条与最新司法解释/裁判观点，禁止无脑套用书中的旧序号（含各地鉴定收费、工期定额地方文件等）。

### 易混淆的邻近方法论
- 与 `dynamic-review` 混淆：把"签证是否有效"当成本技能（应走动态审查），或把"要不要申请造价鉴定"当成动态审查（应走本技能）。
- 与 `trial` 混淆：把"庭前会议如何排期、鉴定人出庭的流程"当成本技能，或把"鉴定意见的实质质证"当成庭审程序。
- 与 `special-issues` 混淆：把"实际施工人能否突破合同相对性"当成本技能，或把"质量责任是否应追加设计单位"当成特殊主体问题。
