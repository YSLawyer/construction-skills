# jianshe-legal-skills · 建工法律技能集（WorkBuddy）

> **当前版本：v1.1**（2026-08-17）——建工技能套件去冲突：邬砚技能明确「裁判规则检索索引」定位，8 技能双向 `related_skills` 互链与分工说明；各技能 frontmatter 标注 `version: 1.1`。

基于周利明、邬砚三本建工经典著作，蒸馏为一组 **WorkBuddy 原子技能**，供建工合同纠纷办案时调用（合同审查、结算举证、庭审应对、鉴定攻防、优先受偿权 / 实际施工人等疑难问题）。

本技能集的核心方法：**把法官的"审判思维"镜像为律师的"办案动作"**——法官每一步审什么，律师就提前准备什么、庭审怎么回应。

## 🔧 安装

将 `skills/` 下的目录复制到 WorkBuddy 用户级技能目录即可（每个子目录是一个独立技能）：

```bash
# Windows（PowerShell / Git Bash）
cp -r skills/* "$HOME/.workbuddy/skills/"

# 或手动把 skills/ 内 8 个文件夹拖入：
#   C:\Users\<用户名>\.workbuddy\skills\
```

安装后在任意 WorkBuddy 会话中，问"合同是什么性质会不会无效""怎么组织结算款证据""法官在庭前会议会问什么""怎么对抗造价鉴定"等，对应技能会自动加载。

## 🧭 使用说明

- **查词条释义 / 裁判规则** → 用 `cclr-pfcc`（词条全书）或 `rule-reconstruction`（邬砚《规则重构》456 条裁判规则索引）。
- **查"法官会怎么审 / 律师怎么应对"** → 用 6 个 `deconstruction-rebuilding-ZhouLiming-*` 技能。
- 两批技能已互相 `related_skills` 关联，可组合使用。
- 每个技能均含 `## 来源与权利` 段，标注来源书籍、原作者与许可限制。
